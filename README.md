# Idle RPG Auto Battle

Starter Godot 4 project for a 2D idle RPG auto-battle game.

## Current Scope

This repository only contains the initial architecture:

- Project settings and autoloads
- Starter main, battle, actor, and HUD scenes
- Modular GDScript stubs
- JSON data files for heroes, enemies, waves, and upgrades
- Coding rules for future development

Full combat, progression, saving, Android export setup, and production UI are intentionally not implemented yet.

## Open In Godot

Open this folder in Godot 4 and run `res://scenes/main/Main.tscn`.
