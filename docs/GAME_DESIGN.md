# Game Design

## 1. Game Title

Temporary title: **Idle Rift Heroes**

## 2. Game Genre

2D idle RPG auto-battle.

## 3. Target Platform

- Windows first.
- Android later.

## 4. Core Gameplay Loop

1. Player opens the game.
2. Heroes fight automatically.
3. Enemies drop gold and EXP.
4. Player upgrades heroes.
5. Player clears waves and bosses.
6. Player gets offline rewards after returning to the game.

## 5. Player Actions

- Upgrade hero.
- Equip items.
- Claim rewards.
- Change team.
- Select stage.
- Fight boss.

## 6. Auto Systems

- Auto movement.
- Auto attack.
- Auto skill.
- Auto wave progression.
- Offline reward calculation.

## 7. MVP Feature List

- Basic hero.
- Basic enemy.
- Auto battle.
- Wave system.
- Boss wave.
- Reward system.
- Upgrade system.
- Save/load.
- Offline reward.
- Basic UI.

## 8. Future Features

- Inventory.
- Equipment.
- Skill upgrade.
- Daily quests.
- Multiple maps.
- Shop.
- Achievements.

## 9. Art Direction

- Fantasy.
- Semi-chibi characters.
- Bright readable colors.
- Mobile-friendly UI.
- Side-view battlefield.

## 10. UI Screen List

- Main Battle Screen.
- Hero Upgrade Screen.
- Inventory Screen.
- Stage Select Screen.
